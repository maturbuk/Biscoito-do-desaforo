# 🥠 Biscoito do Desaforo

Você veio buscar uma mensagem de esperança.
Consultou a bolacha errada.

O **Biscoito do Desaforo** é um app que troca previsões otimistas por sinceridade desnecessária, sarcasmo e conselhos que ninguém pediu.

## 💥 Uma amostra do atendimento

> “Seu relacionamento precisa de diálogo. Mas você prefere consultar um carboidrato.”

> “O universo tem um plano para você. Infelizmente, é o gratuito.”

> “Você é insubstituível. Até alguém aceitar ganhar menos.”

## 🎮 Como funciona

1. Clique em **Quebrar Biscoito**.
2. Receba uma frase aleatória.
3. Questione suas escolhas.
4. Clique de novo porque aparentemente não foi suficiente.

## 📚 Sobre o projeto

Este projeto começou numa aventura de cursinho na Udemy, acompanhando as aulas de React Native do professor **Matheus Fraga** — um professor superlegal que ensinou a fazer um biscoito da sorte.

Aí eu resolvi aplicar minha licença poética.

O professor ensinou componentes, estado, eventos, imagens e sorteio de frases. A decisão de transformar uma bolacha em uma criatura sem educação foi inteiramente minha.

🥠 **A base veio da aula. O desaforo é autoral.**

📖 [Confira o curso do Matheus Fraga na Udemy](https://www.udemy.com/course/crusoreactnative/)

O aplicativo não usa IA para gerar respostas em tempo real. Os desaforos já estão escritos e são sorteados a cada clique. A grosseria foi previamente organizada.

**Este biscoito contém glúten e uma opinião que ninguém pediu.**
